# Awesome-AI-Agent-Memory-Frameworks

# Top AI Agent Memory & Frameworks Ecosystem
**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Long-Term Memory, Stateful Agents, Context Management & Multi-Agent Frameworks*
**Last updated: October 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **AI Agent Memory & Frameworks**. These systems provide short-term and long-term memory, state persistence, context management, and the orchestration layers needed to build reliable, memory-aware agents.

**Examples** include LangGraph Cloud, CrewAI Enterprise, AutoGen, LangChain, Flowise, Dify, Botpress, SuperAGI, Fixie.ai, and AgentOps (the category leaders).

**Open-source emphasis**: Long-term agent memory is a rapidly growing open-source area. **Letta**, **Mem0**, **Zep**, **LangGraph**, **CrewAI**, and related projects make advanced memory-aware agents practical without proprietary lock-in. This section is heavily expanded.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms
- **[LangGraph Cloud / LangGraph Platform](https://www.langchain.com/langgraph)**  
  Managed platform for deploying stateful LangGraph agents with persistence, checkpointing, and production-grade memory and observability features.

- **[CrewAI Enterprise](https://www.crewai.com/)**  
  Hosted and enterprise offerings built on the open-source CrewAI framework, supporting multi-agent teams with memory and knowledge capabilities.

- **[Microsoft AutoGen / Agent Framework offerings](https://microsoft.github.io/autogen/)**  
  Multi-agent conversation framework and related enterprise tooling from Microsoft for collaborative agents (with paths toward Microsoft Agent Framework).

- **[LangChain / LangSmith](https://www.langchain.com/)**  
  Commercial platform and ecosystem around LangChain providing tracing, evaluation, memory patterns, and deployment support for agent applications.

- **[Flowise](https://flowiseai.com/)**  
  Low-code platform for building LLM chains and agents with visual flows and memory/node options (open-source core with hosted plans).

- **[Dify](https://dify.ai/)**  
  Open-source LLM application platform with visual workflows, agent support, and commercial cloud hosting that includes conversation and knowledge memory.

- **[Botpress](https://botpress.com/)**  
  Conversational AI and agent platform with built-in memory, knowledge bases, and enterprise deployment options.

- **[SuperAGI](https://superagi.com/)**  
  Agent framework with commercial offerings focused on autonomous agents, tool use, and memory/knowledge features.

- **[Fixie.ai](https://fixie.ai/)**  
  Platform for building voice and conversational agents with session and context management capabilities.

- **[AgentOps](https://www.agentops.ai/)**  
  Observability and operations platform for AI agents, helping teams monitor runs, costs, and agent behavior (complements memory frameworks).

## Open-Source GitHub Projects
- **[Letta](https://github.com/letta-ai/letta)**  
  Framework for creating advanced AI agents with long-term memory (evolution of MemGPT concepts) — agents can manage their own memory, context windows, and persistent state across sessions.

- **[Mem0](https://github.com/mem0ai/mem0)**  
  Open-source memory layer for AI agents and LLM applications that provides personalized, long-term memory with simple APIs.

- **[Zep](https://github.com/getzep/zep)**  
  Open-source long-term memory store for LLM applications and agents, designed for conversation history, facts, and retrieval.

- **[LangGraph](https://github.com/langchain-ai/langgraph)**  
  Stateful orchestration framework with first-class checkpointing and memory patterns for building durable, multi-step agents.

- **[CrewAI](https://github.com/crewAIInc/crewAI)**  
  Multi-agent framework that supports memory and knowledge sources so crews can retain and reuse information across tasks.

- **[LlamaIndex Memory / Workflows](https://github.com/run-llama/llama_index)**  
  Data and agent framework with memory modules, chat stores, and workflow abstractions for context-aware agents.

- **[Microsoft Agent Framework](https://github.com/microsoft/agent-framework)**  
  Open multi-language framework for production agents with session and state management capabilities.

- **[AutoGen](https://github.com/microsoft/autogen)**  
  Multi-agent conversation framework (largely in maintenance mode) that influenced many later memory and orchestration patterns.

- **[Dify](https://github.com/langgenius/dify)**  
  Open-source platform for LLM apps and agents with built-in conversation memory and knowledge base features.

- **[Documentation and memory pattern guides](https://docs.letta.com/)**  
  Official docs and community resources for implementing long-term memory, context management, and stateful agents with open tools.

### Additional Strong Open-Source Options
- Building memory-first agents with **Letta** for self-managed long-term memory and context control.
- Adding a dedicated memory layer via **Mem0** or **Zep** on top of any agent framework.
- Using **LangGraph** checkpointing for durable, resumable agent state.
- Combining **CrewAI** or **LlamaIndex** with external vector stores for knowledge + conversational memory.
- Accepting that commercial platforms (LangGraph Cloud, CrewAI Enterprise, Dify Cloud, Botpress, etc.) still lead in managed hosting, scaling, and enterprise support for memory-aware agents.

**Frameworks for building custom systems**: Use **Letta** for advanced long-term memory agents → or compose **LangGraph** / **CrewAI** + **Mem0** / **Zep** for flexible memory layers → persist state and retrieve context as needed. Suitable for teams that need full control over agent memory. Many organizations still adopt hosted platforms for reliability and operational tooling.
